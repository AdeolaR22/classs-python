# Python Simple Calculator 🧮

## Project Overview

This project is a simple calculator application built with Python. It performs basic arithmetic operations, allowing users to add, subtract, multiply, and divide two numbers.

The project is designed to practise Python fundamentals, including functions, user input, conditional statements, and error handling.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Accepts two numbers from the user.
- Handles invalid arithmetic operators.
- Prevents division by zero.

## Technologies Used

- Python 3

## How to Run the Project

1. Install Python 3 on your computer.
2. Create a Python file named `calculator.py`.
3. Copy the calculator code into the file.
4. Open your terminal.
5. Navigate to the project folder.
6. Run the following command:

```bash
python calculator.py
```

## Example

**Input:**

```text
Enter the first number: 10
Enter the second number: 5
Enter an operator (+, -, *, /): *
```

**Output:**

```text
The result is: 50.0
```
